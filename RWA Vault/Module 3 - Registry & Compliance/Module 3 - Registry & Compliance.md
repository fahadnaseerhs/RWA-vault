# Module 3 — Registry & Compliance

> 🛸 **Command Center:** For the live status board, open questions, and active agent threads, see **[[00 M3 Dashboard]]**.

The **compliance layer**: turns physical real-world assets into permissioned, legally backed ERC-3643 tokens. An unverified wallet cannot receive or hold tokens, while an agent or multisig can freeze or pause operations according to regulatory and reserve invariants.

- **Depends on:** [[Module 2 - PQ-PKI & Envelope]] (Custodian ML-DSA-65 signed attestation envelopes).
- **Blocks:** [[M4 - Vault Accounting]], and Milestone Gate MS1 (Gold lot tokenised with attested reserve).
- **Done when:** A provider onboards a gold lot unaided, and a direct-contract transfer bypassing compliance is refused on-chain.
